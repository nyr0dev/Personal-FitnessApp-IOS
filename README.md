# ⚡️ Nyr0

A mega-premium, personal workout tracker specifically optimized for **iPhone 16 Pro Max**.

## ✨ Features
- 💎 **OLED Dark Mode:** Deep blacks and neon accents designed for High-End mobile displays.
- 📅 **Smart Dynamic Schedule:** Daily rotating programs (Legs, Core, Upper Body, Full Body).
- 🔔 **Native Push Notifications:** Automated workout reminders at 17:00 (UTC+3) daily.
- 🚀 **Hybrid Architecture:** Supports both Native SwiftUI (.ipa) and Web PWA (Safari Home Screen).
- 🧘 **Active Recovery Logic:** Specialized views for rest days and mobility sessions.

## 📱 Installation

### 1. PWA (Instant Setup)
1. Deploy the files to a host (Vercel, Netlify, or GitHub Pages).
2. Open the URL in **iPhone Safari**.
3. Tap **Share > Add to Home Screen**.

### 2. Native (.ipa)
1. Build the SwiftUI files via **Codemagic** or **Xcode**.
2. Install the generated `.ipa` using **Sideloadly** or **AltStore**.
3. Trust the developer certificate in **Settings > General > Device Management**.
