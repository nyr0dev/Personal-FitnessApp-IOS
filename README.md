# ⚡️ NYR0 | PERSONAL FITNESS APP

A personal workout tracker. Designed for IOS screens and built for high-performance tracking.

## 🚀 Live on Netlify
Deployed as a high-end PWA (Progressive Web Application). 

### How to Install on iPhone:
1. Open the Netlify URL in **Safari**.
2. Tap the **Share** button (the arrow icon at the bottom).
3. Scroll down and tap **Add to Home Screen**.
4. Launch from your home screen for a full-screen, native-like experience.

## ✨ Elite Features
- 💎 **OLED Focus:** Deep blacks and high-contrast neon coral accents.
- 📅 **Dynamic Rotation:** Automatic daily schedule adjustments based on the day of the week.
- ⚡️ **Offline Support:** Powered by Service Workers — works anywhere, even without internet.
- 🔊 **Haptic Feedback:** Interactive UI elements designed for high-end tactile response.
- 📊 **Streak Tracking:** Keep your progress alive with our persistent streak system.

## 🛠 Tech Stack
- **Engine:** Pure JavaScript (ES6+)
- **Design:** Modern CSS3 with Glassmorphism & Micro-animations
- **Platform:** Netlify CMS-less Static Deployment
